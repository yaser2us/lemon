# Emergent Software — Example Pack

This folder expands the core **Emergent Software** idea with concrete examples taken from our design discussion.

The examples are intentionally practical. They are meant to help an AI coding agent connect the philosophy to real software structures, simulations, policies, state transitions, and compilation targets.

## Core Idea

```text
Unknowns are reasoned about.
Knowns are compiled.
```

And:

```text
Experience
   ↓
Behavior
   ↓
Pattern
   ↓
Law
   ↓
Verified Code
   ↓
Primitive
   ↓
Higher-Level Experience
```

## Files

### 01 — Market to Software
Shows why the market analogy matters and how local actors can create global behavior.

### 02 — Money Transfer
Shows a full transaction example from agent interaction to deterministic compiled behavior.

### 03 — App Agent ↔ Backend Agent
Shows how a UI/app can talk to a backend through a shared agent protocol instead of hard-wired API choreography.

### 04 — ROSE / OeRacle
Shows how engineering governance can become executable laws and how repository review behavior may later compile into deterministic checks.

### 05 — Behavior Compiler
Shows how repeated behavior becomes a candidate rule, then tests, then verified code.

### 06 — Non-AI Runtime
Shows that the architecture does not depend on LLMs and can be built first using deterministic agents.

The first goal is not to build a giant platform.

The first goal is to prove one complete loop:

```text
Simulation
   ↓
Behavior Log
   ↓
Pattern
   ↓
Candidate Rule
   ↓
Verification
   ↓
Compiled Behavior
```
